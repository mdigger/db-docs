# PostgreSQL Schema Documentation Generator

Утилита на Go для автоматической генерации актуальной Markdown-документации по структуре базы данных PostgreSQL 18. Инструмент подключается к СУБД, сканирует системные каталоги указанных схем и с помощью Go-шаблонизатора собирает структурированный отчет, включающий таблицы, гипертаблицы TimescaleDB, представления и функции.

---

## Архитектура и компоненты

Проект состоит из трех основных частей:
1. **Код на Go** — устанавливает соединение с БД (через драйвер `pgx`), выполняет мета-запрос к системным каталогам и применяет шаблон.
2. **SQL-запрос (`query.sql`)** — выбирает из `pg_catalog` и `timescaledb_information` информацию о схемах, таблицах, представлениях, функциях, их колонках, индексах и триггерах.
3. **Шаблон документации (`template.tmpl`)** — определяет визуальное представление сущностей в итоговом Markdown-файле.

---

## Возможности и поддерживаемые объекты

Утилита извлекает и документирует следующие объекты базы данных PostgreSQL 18:
- **Таблицы (`table`)** — список колонок с типами данных и комментариями (`col_description`), определения индексов (`pg_get_indexdef`) и триггеров (`pg_get_triggerdef`).
- **Гипертаблицы TimescaleDB (`hypertable`)** — автоматически определяются через каталог `timescaledb_information.hypertables` и документируются аналогично таблицам.
- **Представления (`view`)** — список результирующих полей с типами и комментариями.
- **Функции и процедуры (`function` / `procedure`)** — сигнатуры аргументов (`pg_get_function_arguments`), типы возвращаемых значений (включая многоколоночные `RETURNS TABLE (...)`), а также описания (`obj_description`).

---

## Особенности работы с файлами шаблонов и разметкой

При кастомизации файла шаблона **`template.tmpl`** учитывайте следующие правила безопасности разметки:
- Избегайте использования левостороннего тримминга пробелов `{{-` сразу после открывающих маркеров блоков кода, чтобы не нарушать синтаксическую структуру.
- Для экранирования выводов в чатах или внешних системах документации следите за балансом обратных кавычек.
